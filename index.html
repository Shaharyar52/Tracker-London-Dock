Kitchen Tracker

Quick phone entry for 1st fix, templating, worktop, delivery and 2nd fix.

1. Select plot

2. Enter dates

3. Mark appliances received

Tap an appliance when it arrives. It will turn green in the app and green in the Excel tracker.

Changes are kept on this phone/browser. Download Excel when you want an updated copy of the master tracker.

"Reset this plot" only clears the dates and appliance ticks stored on this phone for the currently selected plot — it does not touch the master Excel file or any other plot.
